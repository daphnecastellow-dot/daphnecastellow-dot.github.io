THE TOOL BENCH

Keep the trail visible.

Nine small research instruments for different places where a claim can blur, drift, collide, lose its source, or outrun its evidence. None of them is a truth machine. Their job is to keep structure inspectable long enough for a researcher to make a better judgment.

HOW THEY FIT

Different questions, separate instruments.

Source lineage→ Evidence type→ Conflict + absence→ Narrative drift→ Claim revision→ Finished reasoning

They can be used together, but they do not depend on one another. Keeping them separate makes each assumption easier to inspect. Tracebridge preserves origin and IDs when records move between tools. Bridgekeeper preserves explicit project state when continuity moves between moments.

01 · CLAIM HISTORY

Threadtrace

Preserves how a working claim changes through revision: earlier wording, status changes, sources, reasons for change, and uncertainty that survives the edit.

The conclusion is a point. Keep the thread that made it intelligible.

View Threadtrace on GitHub →

02 · SOURCE LINEAGE

Sourceweave

Traces where individual details appear within a recorded source lineage and how sources relate to one another.

A repeated detail should not become ancient merely because it survived long enough to be repeated.

View Sourceweave on GitHub →

03 · CONFLICT

Contradiction Atlas

Maps disagreements in date, location, count, identity, sequence, wording, causation, interpretation, and other dimensions without forcing a premature winner.

Do not smooth the wrinkle until you know why it exists.

View Contradiction Atlas on GitHub →

04 · ABSENCE + DEAD ENDS

Negative Space

Records failed hypotheses, missing evidence, inconclusive searches, and parked research paths without turning “not found” into “proven absent.”

A dead end is still part of the map.

View Negative Space on GitHub →

05 · EVIDENCE TYPE

Evidence Ledger

Separates observations, firsthand and secondhand reports, documentary records, interpretations, inferences, and repetitions while preserving dependency.

A pile of statements is not yet an evidence structure.

View Evidence Ledger on GitHub →

06 · REASONING SURFACE

Provenance Lens

Inspects finished claims and writing to distinguish direct support, synthesis, inference, and places where a provenance bridge is still missing.

If the sentence crossed a bridge, keep the bridge visible.

View Provenance Lens on GitHub →

07 · NARRATIVE CHANGE

Claim Drift

Tracks additions, omissions, intensification, certainty shifts, causal shifts, identity changes, temporal changes, and other mutations across versions.

Do not call it a new story until you can show what changed.

View Claim Drift on GitHub →

08 · INTEROPERABILITY

Tracebridge

Passes provenance-aware records between the independent tools using shared bridge IDs, explicit origins, typed links, and native payloads that survive the handoff intact.

Interoperability should preserve provenance, not erase boundaries.

View Tracebridge on GitHub →

09 · CONTINUITY HANDOFF

Bridgekeeper

Preserves compact project-state handoffs across time: what is canonical now, what changed, what was corrected, what remains unresolved, what earlier bridge is superseded, and where authority lives.

Keep enough of the bridge that the next state still knows how it got here.

View Bridgekeeper on GitHub →

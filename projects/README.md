Small builds that are separate from the notebook archive and Rembraith's Workshop.

These projects may have their own release status and licensing decisions. Unless a project explicitly says otherwise, the repository-level [copyright and reuse notice](../COPYRIGHT.md) applies.

## Threadtrace

[Threadtrace](threadtrace/) is an experimental provenance tool for evolving claims.

It preserves:

- the current wording of a claim
- earlier wording
- status changes
- attached sources
- reasons for revision
- unresolved uncertainty

Its working principle is simple:

> Keep the road, not only the destination.
